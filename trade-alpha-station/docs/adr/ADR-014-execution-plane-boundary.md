# ADR-014：商业执行平面与研究平面分离

状态：Accepted
日期：2026-08-26

## 决策

新增 `trade_alpha.execution`，首批模块为 EP-01 交易契约、EP-02 RFQ 证据接入和 EP-03 产品规格版本化。它们复用 M01–M03，但 M01–M03 不反向依赖执行平面。

前三个模块只产生内部、可审计的状态，不包含发送邮件、披露交易对手、价格承诺、付款、签约或下单适配器。`ProductSpecVersion` 冻结只表示后续询价模块可以引用精确规格版本，不代表外部动作获批。

## 原因

- 研究 Claim 与商业交易状态具有不同生命周期。
- 原始证据和解析能力已经存在，不应重复实现。
- 规格冲突、人工冻结和版本差异是执行领域特有语义，不应塞入通用 M03 当前事实视图。
- 结构上缺少 outbound adapter 比仅依赖调用方自律更安全。

## 兼容性

- 新增可选执行包，不改变 M01–M03 已冻结契约。
- EP-02 通过薄适配器调用 M01 EvidenceStore，不把本地上传伪造成 HTTP Retrieval。
- EP-03 通过端口适配 M03 Claim/KnowledgeStore，并保留所有原始 Claim。
